# Project Structure for GenAI Personal Growth Application

## Overview

This document outlines the structure and core pages for the Minimum Viable Product (MVP) of the GenAI-driven personal growth platform. The app is designed to help users align their personal growth with the company’s values, process feedback effectively, and track their development progress.

## Core Pages for MVP

### 1. **Dashboard**

- **Purpose**: Central hub for users to track their overall growth, view insights from reflections and feedback, and access key features.
- **Components**:
  - Overview of progress towards growth goals
  - Upcoming reflection sessions and feedback reviews
  - Quick access to recent reflections and goals
  - Notifications for unfinished tasks or updates

### 2. **Reflection**

- **Purpose**: A space for users to engage in structured reflection based on feedback and personal growth objectives.
- **Components**:
  - Guided reflection prompts (e.g., achievements, challenges, feedback interpretation)
  - Feedback breakdown summary
  - Actionable insights from past reflections
  - Option to set short- and long-term reflection-based goals

### 3. **Personal Growth Roadmap**

- **Purpose**: Displays a clear roadmap for users, linking feedback to personal growth milestones and career goals.
- **Components**:
  - Skill gap analysis based on current role and feedback
  - Recommended actions, resources (courses, mentorships, projects)
  - Progress tracking towards long-term career aspirations
  - Visualization of milestones achieved and next steps

### 4. **Feedback Utilization**

- **Purpose**: Helps users process and apply feedback in real-world scenarios, enhancing their feedback utilization.
- **Components**:
  - History of received feedback
  - Interactive tips for applying feedback in role-specific scenarios
  - Personalized suggestions for improvement based on learning style
  - Scenario-based exercises for applying feedback

### 5. **Values Alignment**

- **Purpose**: Encourages users to evaluate their actions and growth against the core values of AnyMind.
- **Components**:
  - Display of core company values
  - Prompts for aligning daily activities and projects with values
  - Reflections on how recent actions contribute to company philosophy
  - Suggestions for improving alignment with values in daily work

### 6. **Profile Settings**

- **Purpose**: Allows users to manage their personal details, account preferences, and app settings.
- **Components**:
  - Editable profile (name, role, goals)
  - Notification preferences and reminders
  - Integration with other tools (e.g., calendar, task manager)
  - Account management (password, security settings)

### 7. **Help and Support**

- **Purpose**: Provides users with resources for troubleshooting, learning how to use the app, and accessing customer support.
- **Components**:
  - FAQ section covering common issues and features
  - Tutorials and user guides for using the platform
  - Contact support option (e.g., chat, email)
  - Access to knowledge base articles

## Next Steps

1. **Page Creation**: Begin with placeholder pages for the core MVP features listed above.
2. **User Flow**: Define and design the user flow from the Dashboard to other pages (e.g., from Dashboard to Reflection and Growth Roadmap).
3. **UI Components**: Build reusable UI components for consistency across pages (e.g., buttons, inputs, modals).
4. **Placeholder Data**: Integrate placeholder data for reflections, feedback, and growth roadmap for early user testing.
5. **User Testing**: Start testing with a small group to refine the user interface and flow.
